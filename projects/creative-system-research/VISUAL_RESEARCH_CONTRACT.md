# Batch + Symbol Map Research Contract

**Status:** Active working contract  
**Priority:** P0 / Key Project

## Default batch size

The default research round is **10 independent professional cases**.

Conditional exceptions:

- **6–8 cases** for sparse or difficult domains such as pure language, B2B industrial work, scientific/service innovation, or failure cases.
- **Up to 12 cases** for mature gap-filling rounds.
- Avoid defaulting to 20–30 cases per round because depth, prior-art review and visible synthesis degrade.

## Required research loop

```text
SEARCH
→ DECONSTRUCT
→ PRIOR ART
→ SYMBOLIZE
→ DERIVE
→ PRESSURE TEST
→ ACTUAL OUTPUT
→ REVIEW
```

A batch is not complete when cases are only collected or entered into a ledger.

A batch passes only after its visible symbol-map package is completed.

## Four required symbol maps per normal 10-case round

### MAP-01 — Batch Overview

Answers: **What did this round find?**

Should show:

- all cases in the round;
- mother-family mapping;
- executable primitive mapping;
- prior-art distance;
- growth/value mapping;
- primary domains;
- evidence / unknown state;
- deep-dive priority.

### MAP-02 — Deep Distillation

Answers: **What did we actually learn from the strongest case?**

Should move through:

```text
Observed
→ event / system chain
→ parameter decomposition
→ first-order rule
→ relational rule
→ mother mechanism
→ executable primitive
→ parameter space
→ analogical derivation
→ specificity test
→ reverse value derivation
→ prior art
→ failure gate
→ direct execution
```

### MAP-03 — Prior Art / Contrast

Answers: **Where is the boundary?**

Compare:

- current case;
- historical / structural predecessor;
- failure / counterexample.

Output:

- shared structure;
- true increment;
- what is not new;
- failure variable;
- new gate;
- do-not-copy boundary.

### MAP-04 — Derivation / Cross-Domain

Answers: **What new ideas can the mechanism generate?**

Requirements:

- derive 6–12 new candidates;
- distinguish surface replacement, task change, relationship change and system change;
- translate into video / graphic / language / system branches;
- include specificity and failure filters.

## Periodic visual synthesis

Every **+30 independent cases**:

- one **Mechanism Tree Delta** map.

Every **+50 independent cases**:

- one **Coverage Map** showing geography, media, success/failure ratio,
  mechanism density, primitive evidence count, prior-art completion and open gaps.

At R1 completion:

- 3–5 final synthesis maps.

## R1 visible-output expectation

At roughly 200 independent professional cases:

- ~80 standard batch symbol maps;
- ~6 mechanism-tree delta maps;
- ~4 coverage maps;
- ~3–5 final synthesis maps.

Expected total: roughly **90 useful visible research maps**, not 200 decorative case posters.

## Evidence discipline

Every map must distinguish:

- **Observed**
- **Abstracted**
- **Derived**

Derived inference must never be written back as source fact.

The case-description area should normally remain a minority of the map.
Mechanism, comparison, derivation and execution should occupy most of the space.

## Batch acceptance gate

A round passes only when:

- [ ] cases are searched;
- [ ] cases are deconstructed;
- [ ] evidence state is recorded;
- [ ] required prior art is checked;
- [ ] MAP-01 is visible;
- [ ] MAP-02 is visible;
- [ ] MAP-03 is visible;
- [ ] MAP-04 is visible;
- [ ] merges / downgrades / new primitives / gates are recorded;
- [ ] affected domains are mapped;
- [ ] unresolved gaps are carried forward.

The visual map is the user-facing research interface and acceptance surface.
