# SOURCE DISTILLATION NOTES

本包对 WIS v1.0 的吸收是“选择性蒸馏”，不是整体并入。

## 吸收
- WVS：视觉母语、建筑/服装/载具谱系、材料法典、色彩、光影、标识
- WES：宏观→城市→功能区→建筑→室内→材料、场景连续性、镜头进入路径
- WLS：居住、饮食与水、工作、教育医疗、娱乐仪式、普通人的一天
- 强制审计：视觉统一、场景连续性、反设定膨胀

## 不重复吸收
- WCS 世界规则：由 WS-02～14 已覆盖
- WNS 历史/冲突/故事入口：由 WS-16～18 已覆盖
- 世界核心身份主权：继续归 KJ_WORLD_SYNTHESIS RC4

“世界规则优先于单张视觉。”
